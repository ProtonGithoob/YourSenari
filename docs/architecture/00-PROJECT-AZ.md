# YourSenari: layihənin arxitektura icmalı

## Məqsəd
İstifadəçi insan seçir, həyatını səhnələrlə araşdırır, davranışa toxunur və mümkün hiss, məna, ehtiyac, keçmiş təcrübə və sosial təsirləri görür. Başqa insanın baxışına keçir və alternativ davranışın mümkün davamını oynadır.

YourSenari layihə adı, ƏKS-SƏDA təklif olunan istifadəçi brendidir. İlk hekayə 38 yaşlı uydurma rəhbər Kamran haqqındadır. Tarixi şəxsiyyətlər və şəxsi hekayələr sonrakı mərhələlərdir.

## Ekranlar
1. İnsan hekayələri qalereyası.
2. İndiki həyatdan qısa səhnələr.
3. Davranışın daxili qatları.
4. Həyat xətti və keçmişə keçid.
5. İki insanın fərqli perspektivləri.
6. Təkrarlanan münasibət dövrəsi.
7. Alternativ seçim və şərtli davam.
8. Münasibətlər və sosial mühit.
9. Mənbələr, alternativ izahlar, məlum olmayanlar.
10. İstəyə bağlı dini və fəlsəfi məna baxışı.

## Texniki quruluş
React/TypeScript səhnə oynadıcısı, XState vəziyyət idarəetməsi, müəllif üçün React Flow redaktoru təklif edilir. Əsas istifadəçi ekranını qraf redaktoru əvəz etmir: hekayə səhnələrlə anlatılır.

Server modul monolitdir. PostgreSQL hadisələri, əlaqələri, iddiaları, mənbələri və versiyaları saxlayır. Ayrıca işçi proses AI analizi və media hazırlığını icra edir. Səhnələr əvvəlcədən hazırlanır; hər klik üçün AI gözləmək lazım gəlmir.

## AI və məna
AI mümkün izahlar təklif edir. Real insan üçün yeni keçmiş hadisə uydurub bioqrafiyaya daxil edə bilməz. Fakt, şəxsin ifadəsi, uydurma hekayə, ehtimal, alternativ ssenari və mənəvi şərh fərqli saxlanılır.
Məna baxışı ayrıca aktivləşdirilir. Karma, ədalət, mərhəmət və məsuliyyət barədə seçilən ənənənin şərhi göstərilə bilər; bu qat tarixi faktları dəyişmir.

## Mərhələlər
S1: Uydurma hekayə, iki perspektiv, dövrə və alternativ yollar.
S2: Müəllif alətləri, versiyalar və yoxlanmış yayım.
S3: Nəzarət olunan AI təklifləri və mənbə izlənməsi.
S4: Tarixi hekayələr, sosial miqyas və məna baxışları.
S5: Məxfi şəxsi hekayələr və kommersiya funksiyaları.

Repo yoxlananda boş idi. Sənədlər qurulacaq məhsulun qərarlarını və qəbul şərtlərini göstərir; tətbiq və infrastruktur hələ qurulmayıb.
